# Internationalisation

The site is published in several locales from one implementation of each page. The locale list is the single source of truth in `src/i18n/config.ts`; everything else reads from it.

## How it fits together

| Piece       | Where                | Role                                                                                                              |
| ----------- | -------------------- | ----------------------------------------------------------------------------------------------------------------- |
| Locale list | `src/i18n/config.ts` | `locales`, `defaultLocale`, labels, language tags, path helpers                                                   |
| UI strings  | `src/i18n/ui.ts`     | Interface text (menu and footer labels, buttons, headings, form labels) per locale, typed so no key can be missed |
| Content     | `src/content/`       | Editorial text stored per locale (see `docs/content.md`)                                                          |
| Routes      | `src/pages/`         | The default locale at the root, every other locale under `/<locale>/`                                             |
| Views       | `src/views/`         | One component per page type, taking a `locale` prop                                                               |

A route file is deliberately tiny:

```astro
---
import ArtworkView from "@/views/ArtworkView.astro";
import { artworkPaths } from "@/routes";

export const getStaticPaths = artworkPaths;

const { artwork } = Astro.props;
---

<ArtworkView locale="fr" artwork={artwork} />
```

`src/pages/` therefore shows every URL the site serves, while each page exists exactly once in `src/views/`.

## Adding a locale

Example: adding Italian (`it`).

1. **Config** — add `"it"` to `locales` in `src/i18n/config.ts`, with a label in `localeLabels` and a tag in `localeTags`. The type system now flags every place that needs an Italian value.
2. **UI strings** — add an `it` object to `src/i18n/ui.ts` (copy `en` and translate, menu and footer labels included) and register it in `ui`.
3. **Keystatic** — add `it: "Italiano"` to `localeNames` in `src/content-model/keystatic.ts`. Every localised field in the admin gains an Italian input.
4. **Routes** — copy `src/pages/fr/` to `src/pages/it/` and change `locale="fr"` to `locale="it"` in each file.
5. **Content** — open the admin and fill in the Italian fields. Until you do, pages fall back to the default locale.

## Fallback

`text(value, locale)` returns the requested locale's value, or the default locale's when that is empty or missing — never a third language. Required localised fields must have a non-empty default-locale value or the build fails; translations are always optional, so a partially translated site builds and reads in the default language where a translation is missing.

Not yet done, and a reasonable follow-up: marking fallback text with `lang="<default locale>"` so assistive technology switches voice. It touches every text site, so it was left out of the first version.

Removing a locale is the reverse: delete its route folder and remove it from the three files above.

## Changing the default locale

Set `defaultLocale` in `src/i18n/config.ts` and move the corresponding route files to the root of `src/pages/` (the default locale is served without a prefix). Astro does not redirect `/en` → `/` when the default locale is unprefixed (`redirectToDefaultLocale` is only allowed together with `prefixDefaultLocale: true` since Astro 6), so add a redirect at your host if you need one.

## URLs

The URL structure lives in `src/routes.ts`. `routes.artist(locale, artist)`, `routes.exhibition(locale, exhibition)`, `routes.events(locale)` and friends build every internal link, and `routes.artwork(locale, artwork)` chooses `/artworks/…` or `/private-collection/…` from the artwork's Availability. The same file exports the `getStaticPaths` helpers (`artworkPaths`, `artistPaths`, …) the route files re-export, so a page's params and the links to it cannot disagree. Never write a path literal in a component; add a function to `routes.ts` instead.

Underneath, `localizePath(locale, path)` in `src/i18n/config.ts` adds the locale prefix (`/artists` for the default locale, `/fr/artists` otherwise), and `stripLocale(pathname)` / `localeFromPath(pathname)` read the locale back from a URL — the language switcher uses them to link to the same page in another language.
